# OpenTournament

Учебная платформа любительских турниров для лабораторной работы №2 по микросервисной архитектуре.

**Текущий этап — согласование технического задания. Приложение ещё не реализовано.** Публикация проекта не означает готовность перечисленных функций.

Пользователем выбраны:

- Counter-Strike 2, Dota 2 и VALORANT;
- турниры на 4, 8, 16 или 32 команды;
- сетка с выбыванием после одного поражения и верхняя/нижняя сетки с возможным повтором гранд-финала;
- составы по пять игроков без запасных; BO1/BO3/BO5 с отдельным форматом обычных встреч и финала;
- шесть backend-микросервисов, локальный запуск и небольшой пользовательский интерфейс;
- баланс скорости, расхода ресурсов и понятности реализации.
- фиксируемая случайная жеребьёвка, вход с сохранением после обновления страницы и уведомления внутри приложения.

Принятый backend-стек: Python/FastAPI, PostgreSQL, RabbitMQ, REST, Docker Compose. Совместимые версии и конкретные библиотеки проверяются при подготовке окружения. Frontend-технология и композиция согласуются отдельно. Команды запуска и реальные адреса API будут добавлены после первого работающего этапа и проверки на чистом окружении.

Реализация выполняется небольшими проверяемыми этапами с объяснением синтаксиса, архитектуры и упражнением на понимание. Критерий завершения — рабочие сценарии и способность автора объяснить их на защите.
