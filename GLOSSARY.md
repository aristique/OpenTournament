# Язык платформы любительских турниров

Пользователь выбрал любительские турниры как предметную область. Термины прежних примеров магазина остаются в учебных материалах reference/ и не определяют модель проекта.

## Language

**Турнир**:
Организованное соревнование, в котором результаты встреч определяют продвижение участников и итог соревнования.

**Дисциплина**:
Игра, по которой проводится турнир. Начальные дисциплины OpenTournament — Counter-Strike 2, Dota 2 и VALORANT.

**Команда**:
Группа игроков, выступающая в турнире как один участник. Размер активного состава и правила запасных определяются отдельно.

**Вместимость турнира**:
Количество команд, на которое рассчитан турнир: 4, 8, 16 или 32. Число игроков зависит также от состава каждой команды.

**Встреча (матч)**:
Соревнование двух команд в одном узле турнирной сетки, имеющее одного итогового победителя. Одна встреча может включать несколько отдельных игр.

**Верхняя сетка**:
Ветка double elimination для команд, ещё не проигравших ни одной встречи.

**Нижняя сетка**:
Ветка double elimination для команд с одним поражением. Поражение в этой ветке завершает участие.

**Гранд-финал**:
Встреча победителей верхней и нижней сеток.

**Повтор гранд-финала (reset)**:
Дополнительная решающая встреча, назначаемая после победы команды из нижней сетки в первом гранд-финале. После первого финала у обеих команд по одному поражению.
