# Локальный запуск на одном компьютере

Пользователь явно ограничил проект локальным запуском и поставил понимание архитектуры и защиту лабораторной выше эксплуатационной сложности. Проектируем шесть backend-сервисов для одного компьютера; облачное размещение и несколько физических серверов не входят в текущий объём. Это снижает число внешних зависимостей, но не даёт физической отказоустойчивости; независимость сервисов нужно подтверждать отдельными процессами, API, конфигурацией и границами данных.
