# Python/FastAPI, PostgreSQL и RabbitMQ для локальной платформы

После сравнения основных альтернатив пользователь принял backend Python/FastAPI, PostgreSQL, RabbitMQ, REST и Docker Compose. Предпочтение отдано балансу ресурсов, понятности и времени разработки: FastAPI помогает с валидацией/OpenAPI, PostgreSQL даёт транзакции и отдельное владение данными, RabbitMQ позволяет явно показать асинхронное взаимодействие. По сравнению с Go/ASP.NET/Spring выбор уменьшает число одновременно изучаемых инструментов для этого сценария, но не доказывает превосходство по скорости или памяти; производительность измеряется на реализации. Конкретные поддерживаемые версии и клиенты проверяются отдельно; frontend не выбирается этим решением.
