# Серверная сессия для сохраняемого входа

Пользователь подтвердил вход после обновления страницы. Для финальной сверки предложена непрозрачная серверная сессия в identity_db и HttpOnly cookie вместо прежнего проекта access JWT в памяти. Это упрощает сохранение и серверный отзыв одним механизмом без Redis/нового сервиса, но добавляет обращение к identity на каждый защищённый запрос; его отказ блокирует такие операции. Проверки прав ресурса остаются в соответствующем бизнес-сервисе.

Предложенный начальный срок — абсолютные 8 часов без скользящего продления; cookie без Expires/Max-Age сохраняет refresh, а перезапуск браузера отдельно не обещается. Есть проверка origin, CSRF-защита, HTTPS Secure-cookie и явная localhost-dev конфигурация. Выход отзывает запись до подтверждения, но не отменяет уже авторизованный запрос или принятое событие. Источники, альтернативы и тестируемая граница гарантии — [session-design-research.md](../session-design-research.md). Технический выбор ждёт общего согласования ТЗ, пользователь отдельно выбирал поведение, а не протокол.
