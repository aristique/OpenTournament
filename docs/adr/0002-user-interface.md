# Небольшой пользовательский интерфейс для демонстрации

Пользователь выбрал собственную небольшую страницу вместо демонстрации исключительно через документацию API. Это добавляет работу по интерфейсу и его интеграции в недельный срок, но позволяет показать целостный пользовательский сценарий; основной объём приложения по-прежнему составляют шесть backend-сервисов. Технология и набор экранов ещё не утверждены; frontend не входит в число бизнес-микросервисов и не заменяет документацию API.
