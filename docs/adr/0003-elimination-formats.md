# Два вида сеток и условный повтор гранд-финала

Пользователь включил в целевой прототип single elimination и double elimination с возможным повтором гранд-финала. Для double первое поражение переводит в нижнюю ветку, второе завершает участие; победа нижнего финалиста в первом гранд-финале назначает ещё одну полную встречу, чтобы верхний финалист не терял титул после единственного поражения. Это увеличивает объём алгоритма и проверок относительно single-only и финала без reset; для 32 команд требуется проверить до 63 встреч. Конкретный способ посева и переходов в нижней сетке пока предложен в ТЗ, но не утверждён.
